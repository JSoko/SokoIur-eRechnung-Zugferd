# SokoIur-eRechnung-Zugferd
Programm zur Erstellung von Rechnungen im Zugpferd-Format. Auch zum Aufruf durch Drittprogramme

Kompilieren mit

`pyinstaller --noconfirm --onefile --windowed --icon="SokoIur.ico" --add-data "SokoIur.ico;." --name "erechnung_generator" main.py`
